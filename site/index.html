    How to use this

    StartTeach a pointRegistersProgram features3D viewShortcuts

    Start

    1. Pick a program tab, load one from Examples…, press New for a blank program, or Open .ls… to load your own.
    2. Press ▶ Play to watch it run, or step one line at a time with Line ▶ and ◀ Line. Drag the slider to scrub.
    3. Click any line in the editor to jump to where it runs.
    4. Check Findings for problems; click one to go to its line.

    Teach a point (drag the tool head)

    1. In the editor, click the line you want the new move to go after.
    2. Press Teach (under the 3D view). Playback stops and the arm is yours to move.
    3. Drag the yellow ball at the tool tip. A plain drag moves it across X/Y; hold Shift, or choose Drag Z, to move it up and down.
      Or jog it: choose Joint, World, User or Tool, pick a Step, and press the − / + buttons.
    4. Choose L linear or J joint and press Record new point. That adds a new P[n] and a move line after the line you clicked.
    5. To fix an existing point instead: click its line, move the arm, and press Touch up. On a PR[ ] line this sets the register's start value in Position Reg.
    6. Press Teach again to go back to playback.

    New points use the user and tool frame active at the clicked line (shown next to the Record button).

    Registers and position registers

    • Data panel (below the editor): set each R[ ] and PR[ ] once, with a comment. Every program starts from these values, like the pendant's DATA screens.
    • After run shows what the last run left behind. Keep after-run values copies them into the start values.
    • Highlighted rows are used by the open program; a • means it reads that register before setting it.
    • Or set them in the program: R[1]=0, PR[1]=P[2], PR[1,3]=50, PR[2]=LPOS.
    • The Registers & I/O panel shows values at the current line. Flip inputs like DI[1] there, or make one switch after a few seconds.

    Program features

    • CALL PROG runs another open program; CALL PROG(60,R[2]) passes values it reads with AR[1], AR[2].
    • A macro line like OPEN HAND runs the program you pick for it under Settings › Macros.
    • IF …,JMP LBL[ ], IF … THEN / ELSE / ENDIF, SELECT, FOR … ENDFOR.
    • WAIT .50(sec), WAIT DI[1]=ON, and WAIT … TIMEOUT,LBL[ ] (timeout under Settings).
    • Offset,PR[ ] on a move shifts it; DO[1]=PULSE,0.5sec turns an output on briefly.
    • Press Ctrl+Space in the editor for instruction suggestions. Point data is on the Positions tab. Download .ls saves the file.

    3D view

    • Drag empty space to spin the view; scroll or pinch to zoom; right-drag (two fingers on touch) to pan.
    • Path colors: J joint, L linear, C circular, CNT blend.
    • The Paper view shows what the tool draws, seen from above.
